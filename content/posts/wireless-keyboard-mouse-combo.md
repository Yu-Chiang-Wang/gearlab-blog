## 為什麼用這個角度整理？

如果你是看 GearLab 充電器或 iPad 文章過來的，可能會問：**桌面無線鍵鼠組怎麼也算 3C 選物？**

理由很實際——很多人用 MacBook 或 iPad 當主力，但回到家或辦公桌，會想接一套**完整尺寸的無線鍵盤 + 滑鼠**，把筆電墊高當螢幕用，打字更舒服、桌面更乾淨。這時候要挑的不是電競鍵盤，而是「安靜、好配對、續航長、不佔桌面」的無線鍵鼠組。

這篇就用四個維度幫你縮小選擇：**預算、靜音需求、連線方式（2.4G vs 藍牙）、跨裝置切換**。

## 怎麼挑無線鍵盤滑鼠組：4 個關鍵

### 1. 連線方式：2.4G dongle vs 藍牙

- **2.4G（USB 接收器）**：隨插即用、延遲低、不挑系統，但佔一個 USB 孔、接收器掉了麻煩。桌機固定用的最佳解。
- **藍牙**：不佔孔、可連手機平板，適合「一套切多裝置」。少數機型開機階段不能用。
- **雙模（2.4G + 藍牙）**：兼具兩者，價格略高（如 K580、Pebble 2 系列）。

### 2. 要不要靜音？

開放式辦公室、會議室、與家人共用空間，**靜音款**（MK295、K580+M650）差別明顯。靜音主要降低按鍵與點擊噪音，鍵程手感仍是薄膜鍵盤等級，別期待機械鍵盤回饋。

### 3. Mac／iPad 相容性

羅技無線鍵鼠組多為 Windows 鍵位（Win 鍵、注音印刷），接 Mac 能正常用，部分功能鍵要在 **Logi Options+** 重新對應。要原生 Mac 排列 + 美型，**Pebble 2 Combo** 最友善。

### 4. 續航與供電

多數款隨附電池即可用，鍵盤續航常見 1–3 年、滑鼠數月到一年。介意換電池就找內建充電款。下單前看商品頁的供電方式。

## 怎麼選：3 個問題決策

**Q1：固定桌機用，還是要切平板/手機？**
- 固定桌機 → 2.4G 款（MK470 / MK295 / MK235）
- 要切換 → 藍牙/雙模（Pebble 2、K580+M650）

**Q2：在意安靜嗎？**
- 在意 → MK295、K580+M650
- 還好 → MK470、MK235

**Q3：預算？**
- NT$700 內 → MK235
- NT$1,000 內要靜音 → MK295
- NT$1,500 上下要美型/多裝置 → Pebble 2 或 MK470
- 不設限、要多工 → K580 + M650
