## 30 秒先看

- **最重要的一步**：把充電器翻到背面，看「INPUT／輸入」欄。寫 **100–240V ~ 50/60Hz**，全世界的電壓都能用，出國只需要「插頭轉接」，不需要變壓器。
- **轉接頭只解決「插頭形狀」，不解決「電壓」。** 這兩件事分開看，才不會多買或買錯。
- **目的地速查**（台灣是 A / B 型、110V）：日本、美國、加拿大同為 A / B 型，通常不用轉接頭；韓國與歐洲多數國家用 C / F 型（圓孔）；香港、新加坡、馬來西亞、英國用 G 型；澳洲、紐西蘭用 I 型。
- **真正需要變壓器的，是「只標 110V」的電器**：吹風機、電棒、電熱水壺——建議別帶，改用當地借用或買標示 100–240V 的機型。手機、平板、筆電和 GaN 充電器多半是全電壓，但一律以背面標示為準。

## 一、先翻面看：充電器背面的「INPUT」

出國要看的那一行，就印在充電器背面。以我自己在用的綠聯 65W 三孔充電器（型號 CD275）為例：

{{< figure src="/images/posts/best-macbook-charger-2026/ugreen-cd275-spec-label.jpg" alt="綠聯 65W CD275 充電器背面規格標籤特寫，輸入欄標示 100-240V ~ 50/60Hz 1.8A Max" caption="我的 CD275 背面規格牌（同見 MacBook 充電器推薦）：輸入欄就是出國要看的那一行" >}}

銘牌上的輸入欄寫的是 **100-240V ~ 50/60Hz 1.8A Max**，三段各有意義：

- **100-240V**：這顆充電器能吃的市電電壓範圍。涵蓋台灣的 110V、日本的 100V、美加的 120V，也涵蓋歐洲、韓國、東南亞、澳洲的 220–240V。
- **50/60Hz**：涵蓋各地的市電頻率（台灣 60Hz、歐洲多數 50Hz、日本東西不同），頻率不用另外處理。
- **1.8A Max**：最大輸入電流。這個數字第四節挑轉接頭時會用到——轉接頭本身也有額定電流，要涵蓋它。

這顆是我在 [MacBook 充電器推薦](/posts/best-macbook-charger-2026/)裡實測過的 No.2，它有個和出國有關的缺點：**插頭是固定式、不可摺疊**，打包時要留意別讓插腳刺到其他東西。

另一個常被搞混的地方：同一張銘牌上還有「輸出（OUTPUT）」欄，USB-C 那一排 5V／9V／12V／15V／20V 是充電器和裝置用 PD 協定協商出來的檔位，**跟出國要看的市電電壓是兩回事**（見下方常見問題，或[USB-C PD 是什麼](/posts/usb-c-pd-explained/)）。

如果 INPUT 欄只寫 110V 或 100–127V，到 220–240V 的國家就需要變壓器，見第五節。

## 二、電壓和插頭是兩回事：三種東西各解決什麼

| 東西 | 解決什麼 | 不解決什麼 | 什麼時候需要 |
|---|---|---|---|
| **插頭轉接頭**（旅行轉接頭） | 插頭形狀對不上插座 | 不改變電壓 | 目的地插座型號和你的插頭不同 |
| **變壓器**（電壓轉換器） | 把 220–240V 降成 110V 等 | 不改變插頭形狀 | 電器只支援 110V（INPUT 沒寫到 240V） |
| **萬國轉接頭**（多國通用） | 一個轉接頭涵蓋多種插頭形狀，有些內建 USB 孔 | 多數不改變電壓 | 一趟旅程跨多國，或不想每國買一個 |

判斷口訣：**看 INPUT 決定要不要變壓器，看目的地決定要哪種轉接頭。** 現在多數 USB-C 充電器的 INPUT 都是 100–240V，所以大多數人只需要處理後者。

## 三、目的地速查表（12 組）

| 目的地 | 電壓 | 頻率 | 插座型號 | 從台灣帶去的插頭要轉接嗎 |
|---|---|---|---|---|
| 台灣（對照） | 110V | 60Hz | A / B | — |
| 日本 | 100V | 東日本 50Hz、西日本 60Hz | A / B | 通常不用 |
| 美國、加拿大 | 120V | 60Hz | A / B | 通常不用 |
| 韓國 | 220–230V | 60Hz | C / F | 要（圓孔） |
| 中國 | 220–230V | 50Hz | A / I | 兩種都常見，建議帶 |
| 香港、澳門 | 220–230V | 50Hz | G | 要 |
| 新加坡 | 230V | 50Hz | G | 要 |
| 馬來西亞 | 230–240V | 50Hz | G | 要 |
| 泰國 | 220–230V | 50Hz | A / B / C / O（多為通用孔） | 常可直插，仍建議帶 |
| 越南 | 220–230V | 50Hz | 以 A / C 為主 | 視地區而定，建議帶 |
| 英國 | 230V | 50Hz | G | 要 |
| 歐洲主要國家（法、德、義、西、瑞士） | 230V | 50Hz | 以 C / F 為主（法 C / E、義 C / F / L、瑞士 C / J） | 要 |
| 澳洲、紐西蘭 | 230–240V | 50Hz | I | 要 |

幾個讀表重點：

- **「通常不用」＝插座型號和台灣相同（A / B）；「要」＝型號不同。** 老舊場所仍可能對不上，實際以當地住宿的插座為準。
- **日本電壓是 100V，比台灣的 110V 略低**，INPUT 涵蓋 100V 就沒問題。東京一帶屬 50Hz、大阪京都一帶屬 60Hz，但 INPUT 標 50/60Hz 的充電器不受影響。
- **電壓欄的區間**（如 220–230V）是因為我對照的兩份來源對同一國的標稱值略有出入，寫成區間比挑一個數字誠實。反正它們都落在全電壓充電器的 100–240V 範圍內。
- 表中「插座型號」是**牆上插座的形狀**，轉接頭買的是「台灣插頭 → 該型號插座」的方向。

## 四、三種帶法比較

| 帶法 | 適合誰 | 優點 | 要留意 |
|---|---|---|---|
| **自己的充電器 + 插頭轉接頭** | 大多數人 | 輸出瓦數由你的充電器決定，轉接頭不改變輸出 | 轉接頭有自己的額定電流，要涵蓋充電器 INPUT 標示的最大輸入電流（例如上面 CD275 的 1.8A Max） |
| **多孔 GaN 充電器 + 一個轉接頭** | 帶 2 台以上裝置（手機＋平板＋筆電） | 一顆充電器加一個轉接頭就夠，少佔一個插座、少帶一顆 | 多孔同時使用會降速：我的 CD275 三孔全用時，MacBook Air 端降到 20W 上下（見 [MacBook 充電器推薦](/posts/best-macbook-charger-2026/)） |
| **萬國轉接頭（內建 USB 孔）** | 跨多國、只充手機 | 一個東西涵蓋多國，不必每國買一個 | 內建 USB 孔的輸出功率要看它自己的標示（單孔與總輸出瓦數），別預設它能充筆電 |

如果你本來就帶兩台以上的裝置，第二種通常最省事：一顆多孔充電器，只需要處理**一個**插頭轉接。多孔款怎麼挑、三孔全用會降到多少，見[多孔 GaN 充電器推薦](/posts/multi-port-gan-charger-2026/)。

## 五、真正需要變壓器的情況

變壓器要處理的是**電器只支援 110V** 的情況，最常見在電熱類：吹風機、電棒（捲髮／直髮）、電熱水壺。這類電器如果銘牌沒有寫到 220–240V，到 220–240V 的國家只靠插頭轉接會讓電器承受過高電壓，可能損壞，甚至有安全風險。

更務實的做法是**這類電器別帶**：改用當地住宿提供的，或現地購買，或買銘牌標示 100–240V（或可切換電壓）的機型。

至於手機、平板、筆電這類靠 USB 或專用充電器供電的裝置，只要看**那顆充電器**的 INPUT 欄——通常是 100–240V，不需要變壓器。

## 六、出發前 5 項檢查

1. **翻面看 INPUT**：是否含 100–240V。
2. **用第三節對照表確認目的地插座型號**，準備對應的轉接頭；一趟跨多國就把所有型號列出來。
3. **線材要跟上**：想用筆電級瓦數充電，線要標示支援 100W（5A），見 [Type-C 充電線推薦](/posts/usb-c-charging-cable/)裡的規格說明。
4. **行動電源放隨身行李**，出發前先看機身 Wh 標示，規則見[行動電源推薦](/posts/power-bank-recommendation/)的「能不能帶上飛機」一節。
5. **只標 110V 的電器留在家裡。**

## 常見問題

### 去日本需要買特別的充電頭或轉接頭嗎？

不需要買特別的「日本充電頭」。日本電壓 100V、插座型號 A / B，和台灣型號相同，插頭形狀通常直接插得上；充電器只要 INPUT 涵蓋 100V（標 100–240V 的都涵蓋）就能用。日本頻率分東日本 50Hz、西日本 60Hz，但 INPUT 標 50/60Hz 的充電器不受影響。唯一要留意的是：如果你的插頭帶接地腳，而住宿的插座沒有對應孔位，才需要另外處理。

### USB-C 充電器上寫的電壓，跟出國要看的電壓是同一個嗎？

不是。充電器上其實有兩組電壓：**INPUT（輸入）**是牆壁端，範圍例如 100–240V，出國要看的是這一組；**OUTPUT（輸出）**是 USB-C 端的 5V、9V、15V、20V 等檔位，是充電器和裝置用 PD 協定協商出來的，不受出國影響。判斷要不要變壓器，只看 INPUT。PD 的電壓檔位怎麼運作，見[USB-C PD 是什麼](/posts/usb-c-pd-explained/)。
